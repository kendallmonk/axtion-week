# Axtion Week

Weekly system view — work blocks, domains, principles. Static HTML, zero dependencies beyond a Google Fonts import. No build step.

## Deploy to Vercel

1. GitHub → **+** → **New repository** → name it `axtion-week`. Leave "Add a README" unchecked. Create.
2. On the new repo page, click **"uploading an existing file."**
3. Drag in `index.html` from this folder.
4. Scroll down → **Commit changes** (commit directly to `main`).
5. Vercel → **Add New** → **Project** → import `axtion-week`.
6. Framework preset: **Other**. Deploy.

Every push to `main` redeploys automatically. To update the week, edit `index.html` directly on GitHub (pencil icon) the same way as the other apps.
